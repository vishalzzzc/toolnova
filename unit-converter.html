What is a Unit Converter?

A unit converter allows you to convert measurements from one unit to another. ToolNova supports length, weight, temperature, data and time conversions.

Supported Units

  • Length — meter, kilometer, centimeter, millimeter, mile, yard, foot and inch.
  • Weight — kilogram, gram, milligram, pound and ounce.
  • Temperature — Celsius, Fahrenheit and Kelvin.
  • Data — byte, kilobyte, megabyte, gigabyte and terabyte.
  • Time — second, minute, hour, day and week.

How to Use

  1. Select a category.
  2. Select the From unit.
  3. Select the To unit.
  4. Enter a number.
  5. Press Convert.
